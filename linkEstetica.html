Instrucciones para jugar al SET

Regla para formar un SET

Para formar un “set”, cada característica (forma, color, relleno y cantidad) tiene que cumplir una regla.

Esa regla dice que tienen que ser: o todas iguales, o todas distintas en esa característica.

Si las cuatro características cumplen la regla, entonces las cartas forman un SET.

Pero, si alguna característica no cumple la regla: o sea, si en alguna característica no son ni todas iguales ni todas distintas, entonces las cartas ya NO forman un SET.

Veamos algunos ejemplos
1) Todas iguales → SÍ forman un SET

¿Se cumple la regla “todas iguales o todas distintas”?

  1. Todas tienen la misma forma.
  2. Todas tienen el mismo color.
  3. Todas tienen el mismo relleno.
  4. Todas tienen la misma cantidad.

Entonces, estas cartas forman un SET.

2) Todas distintas → SÍ forman un SET
  1. Las formas son todas distintas.
  2. Los colores son todos distintos.
  3. Los rellenos son todos distintos.
  4. Las cantidades son todas distintas.

Como todas cumplen la regla, forman un SET.

3) Mezcla de iguales y distintas → SÍ forman un SET
  1. Las formas son iguales.
  2. Los colores son distintos.
  3. Los rellenos son iguales.
  4. Las cantidades son distintas.

La regla se cumple en todas las características.

4) Una característica rompe la regla → NO forman un SET
  1. Las formas sí cumplen la regla.
  2. El color NO cumple la regla: Hay dos verdes iguales y una azul distinta.

Entonces, estas cartas NO forman un SET.
